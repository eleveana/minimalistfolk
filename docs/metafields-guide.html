Internal guide

Product Metafields

These fields show up on every product (Admin → Product → Metafields section). They control special theme behaviors on a per-product basis, with no code changes.

Individual fields

Each one acts on its own, on the product where it's filled in.

01

Coming Soon

Pre-launch

Flags the product as pre-launch. When on, the theme hides the price and shows the “Notify Me” flow instead of the buy button.

TypeTrue / False
How to setChoose True while it's not for sale. Set False (or Clear) at launch.
How it looks in the product admin
02

Fit

Sizing scale

Shows a fit guide on the product page — where the item sits on the Small → Large scale.

TypeNumber (1–5)
How to setEnter a number from 1 to 5. It highlights that point on the scale. If empty, it defaults to True to size (3).
What each number means
1Runs small— size up
2Slightly small
3True to size— most common
4Slightly large
5Runs large— size down
How it looks on the product page (here: 3 = True to size)
03

Size charts

Measurements popup

Links the product to the size chart that opens in the sizing popup.

TypeReference (chart)
How to setPick a ready-made entry — Content → Metaobjects → Size Chart (e.g. “Kids Tees”, “Track Shorts”). Empty = popup won't appear.
New chart?If the right one isn't listed, create it first: Size Chart → Add entry, then select it here.
Content → Metaobjects → Size Chart — the entries you can choose from
04

Pair with

Complete the look

Any product you add here shows up on the product page under the “Complete the look” section. If none is set, that section is hidden for that product.

TypeList of products
How to setSearch and select the pieces that go together.
How it looks on the product page
The “Siblings” group — they work together

Link the same style across different colors/prints, showing the swatch dots on the card and the product page.

Why it matters Each color/print is a separate product in Shopify. Without this link, those pages are unrelated dead-ends and customers never discover the other versions. With it, they can hop between every version from any one product page — and when you launch a new color, just add it to the collection and it shows up on all the siblings automatically.
05

Siblings

By collection

Links the variations by collection: you enter the handle of a collection that gathers all versions of that style.

TypeText (handle)
Exampletrack-shorts
06

Sibling Color

Swatch tooltip · optional

The name of this product's version. It appears as the tooltip when you hover a swatch in “Also available in”. Each sibling has its own.

TypeText
ExampleGreen + Yellow
OptionalSwatches still appear and link without it — you only lose the hover label.
The “Green + Yellow” label is the swatch tooltip
07

Sibling products

By manual list

Alternative to a collection: you manually list the other versions of the same style.

TypeList of products
How to setSelect the other color/print versions.
Use Siblings (collection) OR Sibling products (list) to make the link — you only need one. Either way, fill in Sibling Color on each product so the swatch shows the right label.

How it looks in the store

The same fields, filled in and live on the product page.

A

Color/print swatches (Siblings)

The 4 versions of the same style, linked by the Sibling products + Sibling Color fields.

B

“Coming Soon — Notify Me” button

Appears automatically when the Coming Soon field is set to True — it replaces the buy button.

How to set it up

  1. Admin → Products → open the product.
  2. Scroll to Metafields (the section in the screenshot).
  3. Click the field and type or select the value.
  4. Save (top-right corner).
In bulk
To fill in many products at once (e.g. the color for a whole collection): Products → select several → Edit products → add the metafield columns in the bulk editor.
